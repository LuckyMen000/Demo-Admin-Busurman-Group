АДМИН-ПАНЕЛЬ BUSURMAN GROUP — UX v4.0

Пять всегда доступных разделов: Обзор, Сайт, Медиа, Продажи, Система.
Подразделы открываются вкладками в контенте — аккордеонов в меню нет.
Для входа: admin@demo.local / demo123
Все данные хранятся только в браузере (localStorage), реального backend нет.

BUSURMAN GROUP — прототип административной панели v3
Основа: «Структура сайта Айдара Бусурман — ТЗ v2», 22.10.2026

СОСТАВ
- login.html  — отдельная страница входа
- index.html  — панель и SVG-иконки
- style.css   — минималистичные стили, адаптивная версия
- app.js      — навигация, формы, демо-данные и вся логика

КАК ОТКРЫТЬ
1. Распакуйте архив, оставив все файлы в одной папке.
2. Откройте login.html в современном браузере.
3. Демо-логин: admin@demo.local
   Демо-пароль: demo123
Если браузер не разрешает localStorage при запуске через file://,
запустите локальный сервер в папке проекта:
   python3 -m http.server 8000
и откройте http://localhost:8000/login.html

ВОЗМОЖНОСТИ ДЕМО v2
1. События: добавление, редактирование, дублирование черновиком,
   перенос даты / времени / площадки, отмена, календарь по месяцам.
2. Тарифы: несколько тарифов на программу, цена, предоплата,
   правила видимости цены, статус, редактирование и удаление.
   Тарифы в демо не являются согласованными реальными предложениями.
3. Заявки: табличный и канбан-вид, карточка клиента, история,
   заметки, ответственное лицо, изменения статуса и ссылка WhatsApp.
4. Медиабиблиотека: список ссылок и локальная загрузка изображений
   JPG/PNG/WebP до 500 КБ, карточки материалов и превью изображения.
   Видеофайлы не загружаются, допускается URL видео.
5. Предпросмотр: макет для программы, мероприятия и слайдера;
   переключение телефон/компьютер. Это не реальная публичная страница.
6. Аналитика: демонстрационная статистика заявок и оплат,
   источники заявок, популярные программы, выгрузка в CSV.
7. Сотрудники: добавление, изменение и удаление сотрудников,
   роли Администратор / Редактор / Менеджер.
   Переключение роли в шапке имитирует разграничение прав.
8. Сохранены прежние возможности: обзор, каталог 8 программ,
   контент главной, сообщество, видеоотзывы, медиа, оплаты, настройки.

ОГРАНИЧЕНИЯ
- Демо не содержит backend, настоящей базы данных и авторизации.
- Демо-доступ и роли не обеспечивают безопасность.
- Изменения хранятся только в localStorage текущего браузера.
- Нет интеграции с amoCRM, Freedom Pay, Kaspi Pay, аналитическими сервисами.
- Все даты, суммы, клиенты и события демонстрационные.
- CSV отражает только локальные демо-данные.
- Кнопки в предпросмотре не оформляют реальные заявки или оплаты.
- Для возвращения исходных данных используйте «Настройки» → «Сбросить демо-данные».
- Обновление v2 использует прежний ключ локального хранилища
  и добавляет недостающие разделы к сохранённым ранее данным.

ДЛЯ РЕАЛЬНОГО ЗАПУСКА понадобятся сервер, аутентификация,
управление доступом на сервере, БД, загрузка медиа в объектное
хранилище и полноценные интеграции.

ОБНОВЛЕНИЯ v3 (UX)
- Меню сокращено до 5 верхнеуровневых элементов: Обзор, Сайт,
  Медиа, Продажи, Система; вложенные пункты раскрываются по нажатию.
- Тарифы и предоплаты перенесены в контекст программы: две вкладки
  «Программы» и «Тарифы и предоплаты».
- Предпросмотр доступен из «Страницы сайта» и карточек программ.
- Переименованы разделы для краткости; все маршруты сохранены.
- Форма входа: trim пробелов вокруг email и пароля исключительно
  для демонстрационной версии; пустые поля и пароль из одних пробелов
  не принимаются; добавлено управление видимостью пароля и ошибки.
- Сохранены сценарии v2 и существующие локальные данные пользователя.


ОБНОВЛЕНИЕ v5.0 — ВЛОЖЕННАЯ НАВИГАЦИЯ + АНИМАЦИИ
- Слева всегда видны Обзор, Сайт, Медиа, Продажи, Система.
- Подразделы находятся непосредственно в сайдбаре; у каждого своя SVG-иконка.
- Нажатие на группу плавно раскрывает/сворачивает ее. Открыта одна группа.
- Нажатие на подраздел открывает соответствующую страницу.
- Прямые ссылки вида index.html#/events и переходы браузера открывают
  соответствующую группу автоматически.
- Анимации: раскрытие групп, переход страницы, диалоги и hover.
- Уважает системную настройку сокращения анимаций.
- Сохраняются локальные данные, демо-авторизация и все функции v4.
- Только HTML/CSS/JS; иконки встроены в HTML и доступны офлайн.
