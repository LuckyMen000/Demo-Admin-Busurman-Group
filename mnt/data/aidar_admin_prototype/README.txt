ФАЙЛЫ
- login.html — отдельная страница входа
- index.html — административная панель
- style.css — нейтральные wireframe-стили
- app.js — навигация, формы, фильтры, тестовые данные, localStorage

ЗАПУСК
1. Распакуйте ZIP в отдельную папку.
2. Самый простой вариант — открыть login.html в браузере.
3. Если браузер ограничивает локальное хранилище для файлов file://,
   запустите локальный сервер в папке проекта:
      python -m http.server 8000
   Откройте http://localhost:8000/login.html

- Просмотр демонстрационных оплат
- Редактирование слайдов, направлений и цифр главной
- Сохранение в localStorage и сброс демо-данных
- Адаптация под мобильные экраны

ВАЖНО
- Это интерактивный UI-прототип, не production-система.
- Демо-авторизация выполняется на клиенте и не защищает данные.
- Реальных платежей, интеграции Kaspi/Freedom Pay/amoCRM,
  базы данных, отправки уведомлений и backend здесь нет.
- Даты, цены, имена и события являются примерами, а не утверждёнными данными.
- Функции редактирования заявок, блоков и проектов — предположения
  для прототипирования; детальные CMS-поля в ТЗ не зафиксированы.
